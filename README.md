# Landing Page AUX Noise 🎧

## 📄 Deskripsi
AUX Noise adalah perusahaan teknologi kreatif yang bergerak di bidang **musik**, **video**, **desain**, dan **sound engineering**. Website ini merupakan landing page resmi AUX Noise yang menampilkan profil perusahaan, layanan utama, dan kontak yang dapat dihubungi.

Website ini dibangun menggunakan framework **Bootstrap 5**, sehingga memiliki tampilan yang **responsif** di berbagai ukuran layar.

---

## 💻 Teknologi yang Digunakan
| No | Teknologi | Deskripsi |
|----|------------|------------|
| 1 | **HTML5** | Struktur utama halaman website |
| 2 | **CSS3 (Bootstrap 5)** | Desain dan tata letak responsif |
| 3 | **Bootstrap Icons** | Ikon pada bagian fitur dan sosial media |
| 4 | **JavaScript (Bootstrap Bundle)** | Interaktivitas dan validasi form |

---

## 🧩 Komponen Website
| Bagian | Deskripsi |
|---------|------------|
| **Header/Navigation** | Berisi logo AUX Noise dan menu navigasi yang responsif |
| **Hero Section** | Bagian pembuka dengan headline dan tombol CTA (Call To Action) |
| **Features Section** | Menampilkan 3 fitur utama dengan ikon dan deskripsi |
| **About Section** | Menjelaskan profil AUX Noise dan bidang usaha kreatif yang digeluti |
| **Informasi Tambahan** | Tambahan informasi layanan dan keunggulan AUX Noise |
| **Contact Form** | Formulir kontak interaktif untuk mengirim pesan ke email perusahaan |
| **Footer** | Berisi copyright dan link ke media sosial |

## 🧠 Cara Menjalankan Project
1. Clone repository ini menggunakan perintah:
   ```bash
   git clone https://github.com/USERNAME/aux-noise-landing.git
   ```
2. Buka folder project:
   ```bash
   cd aux-noise-landing
   ```
3. Jalankan file `index.html` di browser (klik dua kali atau drag ke browser).

---

## 🌐 Deployment
Website dapat di-host secara gratis menggunakan **GitHub Pages**:
1. Push semua file ke repository GitHub.
2. Masuk ke pengaturan repository → **Pages** → Pilih branch `main` dan folder `/root`.
3. Tunggu beberapa menit hingga link aktif.
